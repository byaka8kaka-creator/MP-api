# Свод рекламных кампаний Wildberries по брендам и периодам

**Свод РК** настраивается во вкладке **Обработки**. Пример объединяет ответы трёх опубликованных шаблонов одного запуска, копирует листы `fullstats`, дополняет его основной лист колонками **Артикул WB** и **Бренд** и добавляет лист **Свод РК**. Источники, шаги, листы и колонки можно отредактировать.

При обновлении приложения для существующих выгрузок со сводом создаётся обработка **Свод РК**, и она привязывается к выгрузке автоматически. Даты и расписание берутся из сохранённой выгрузки.

## 1. Проверьте три готовых шаблона

В **Шаблоны запросов** найдите опубликованные шаблоны для одного кабинета продавца. Названия и папки могут быть своими. Путь к сохранённым строкам виден в **Настроить → Ответ и колонки → Путь к массиву строк** или в `response.rows` последней опубликованной версии через **Ещё → Версии**.

| Запрос | Путь к строкам | Что берёт свод |
| --- | --- | --- |
| `GET /adv/v3/fullstats` | `$` | `advertId`, показатели и листы статистики |
| `GET /api/advert/v3/adverts` | `adverts` | `advertId → nms[].nmId`, состав кампании |
| `POST /api/analytics/v3/sales-funnel/products` | `data.products` | `product.nmId → product.brandName`, справочник брендов |

Для состава и воронки проверьте, что их фильтры и пагинация охватывают нужные кампании и товары. Если `fullstats` и состав уже получают список кампаний из `/adv/v1/promotion/count` через зависимость, эта настройка используется при запуске свода.

## 2. Настройте обработку и выберите её в выгрузке

1. Откройте **Обработки → Новая обработка**. Выберите область **Вся выгрузка** и нажмите **Загрузить пример «Свод РК»**. Кнопка появляется, когда опубликованы все три подходящих шаблона. Для ранее настроенного свода откройте **Изменить** в строке обработки.
2. В **Источниках обработки** проверьте шаблоны для `statistic`, `adverts` и `products`. Если подключено несколько кабинетов, выберите три шаблона нужного кабинета. Сохраните обработку.
3. Откройте **Выгрузки → Создать выгрузку**. Задайте название, например **Реклама по брендам**, и выберите **Excel (.xlsx)**.
4. Добавьте те же три шаблона через **Добавить источник**. Для каждого выберите своё подключение, папку и шаблон. В поле **Обработка всей выгрузки** выберите **Свод РК**.

## 3. Заполните даты у двух источников

Периоды задаются в карточках соответствующих источников. Приложение отправляет даты каждого источника согласно его шаблону.

| Источник | Поля для заполнения | Для чего |
| --- | --- | --- |
| `fullstats` | **Начало периода** и **Конец периода**, в запросе `beginDate` и `endDate` | Получить рекламную статистику и определить период строк на листе **Свод РК** |
| Воронка продаж | `selectedPeriod.start` и `selectedPeriod.end`, обычно поля **Начало** и **Конец** внутри выбранного периода | Получить карточки товаров с `product.nmId` и `product.brandName` |
| Состав кампаний | Обычные настройки шаблона | Получить список артикулов в каждой кампании |

Например, в обоих источниках можно указать **21.11.2026–22.11.2026**. Периоды задаются независимо. Если шаблоны используют поля типа `date`, можно выбрать фиксированные даты или **Относительно дня запуска**. Смещения `-2` для начала и `-1` для конца дают два последних завершённых дня.

Если `fullstats` делит диапазон на части по 31 дню, на листе **Свод РК** будут фактические границы каждой части. Период воронки определяет выборку карточек для поиска брендов.

## 4. Запустите и проверьте Excel

Нажмите **Сохранить**, затем **Запустить** у новой выгрузки. Откройте **Журнал → Подробнее → Открыть папку файлов**.

- На основном листе статистики найдите **Артикул WB** и **Бренд**. Если у кампании несколько товаров, их уникальные артикулы перечислены в одной ячейке, а бренды — в соседней.
- В книге будут листы, настроенные в шаблоне `fullstats`, например **Кампании по дням** и **Средняя позиция**.
- В **Свод РК** каждая строка соответствует бренду и паре дат **Начало периода** и **Конец периода**. Просмотры, клики, добавления в корзину, заказы, отмены, расходы и сумма заказов складываются по этой тройке.

## Как изменить свод

- **Шаги обработки → Соединение наборов**. `itemsWithBrands` сопоставляет артикулы и бренды, а `campaignMatches` добавляет состав рекламной кампании к статистике по `advertId`. Ключи и действия при нескольких совпадениях можно изменить в этих шагах.
- **Шаги обработки → Распределение показателей по детализации**. `brandMetrics` определяет, к какому бренду и с какими показателями отнести строку. Для нового показателя здесь задаются поле из итога кампании и поле из детализации по товарам.
- **Шаги обработки → Группировка и итоги**. В шаге `summary` измените поля, по которым нужно группировать строки, и список итоговых показателей. По умолчанию это период и бренд.
- **Листы результата**. Разверните нужный лист и откройте **Колонки листа**. Для каждого столбца выберите поле и подпись. Например, чтобы добавить показатель в свод, внесите его в `brandMetrics` и `summary`, а затем добавьте колонку с именем его выходного поля на листе **Свод РК**.

Для проверки выберите **Проверка на сохранённом запуске → Предпросмотр**. Приложение покажет, сколько строк прошло через каждый шаг, где не нашлись совпадения, и как будут выглядеть колонки. Готовый файл по текущей обработке можно создать через **Журнал → Подробнее → Применить обработку выгрузки**. [Настройка обработки всей выгрузки](workbook-processing.md)

## Как учитываются кампании с несколькими товарами по умолчанию

Если по составу кампании определён один бренд, итог кампании за период учитывается под этим брендом один раз. Например, при двух товарах бренда и 100 просмотрах кампании в свод добавляется 100 просмотров.

Для кампании с несколькими брендами приложение берёт детализацию `days → apps → nms` из `fullstats` и сверяет сумму семи показателей по товарам с итогами кампании. Если детализация сходится, показатели относятся к соответствующим брендам. Когда детализация отсутствует или её суммы расходятся с итогом, весь итог кампании входит в строку **Несколько брендов**. Артикулы без найденного бренда учитываются под **Бренд не определён**. Состав кампаний берётся из ответа `/api/advert/v3/adverts` этого запуска.

Если один из запросов дал частичный результат, журнал покажет это у его карточки. В Excel используются сохранённые ответы этого запуска. По **Открыть журнал** можно проверить причину, а по **Просмотр строк** — поля ответов.
