# Информация о медиакампаниях Wildberries

Метод `GET /adv/v1/advert` возвращает объект одной медиакампании. Метод `GET /adv/v1/adverts` даёт список кампаний, из которого можно взять их `advertId`. В запрос деталей это число передаётся в строке запроса под именем `id`, например `GET /adv/v1/advert?id=23569`.

Для сохранения целой кампании используйте версию MP API с настройкой `singleObject`. Начните с ручного запроса по одному известному ID, затем подключите список к автоматической выгрузке.

## 1. Проверьте подключение

1. В **Шаблоны запросов** найдите рабочий **Список медиакампаний** (`/adv/v1/adverts`). Откройте **Настроить** и запомните его подключение, адрес и профиль авторизации.
2. В **Подключения** проверьте URL адреса. Для деталей медиакампаний нужен `https://advert-media-api.wildberries.ru`. Если адрес уже есть в этом подключении, выберите его для нового шаблона.
3. Если адреса нет, откройте **Подключения → нужное подключение → Подключение**. В массив **Именованные адреса (JSON)** добавьте объект, сохранив остальные адреса.

   ```json
   {
     "id": "advert-media",
     "name": "WB Медиа",
     "url": "https://advert-media-api.wildberries.ru"
   }
   ```

4. Используйте тот же профиль с заголовком `Authorization`, что и у списка. Если адрес новый, откройте **Авторизация**, выберите этот адрес, профиль и среду **Рабочая**, затем сохраните токен WB с доступом к категории «Продвижение». У нового адреса своя запись авторизации. Токен вводится в поле `Authorization` без префикса `Bearer`.

Связанные шаблоны должны находиться в одном подключении. Внутри него можно выбрать именованный адрес для каждого шаблона.

## 2. Создайте шаблон по одному ID

В **Шаблоны запросов** выберите подключение списка и нажмите **Новый шаблон**.

| Поле | Значение |
| --- | --- |
| Название | `Информация о медиакампаниях WB` |
| Папка | Например, `Медиакампании` |
| Адрес подключения | Адрес с URL `https://advert-media-api.wildberries.ru` |
| Авторизация | Профиль с заголовком `Authorization` |
| Метод | `GET` |
| Путь запроса | `/adv/v1/advert` |
| Пагинация и период → Механизм | `Без пагинации` |

В **Пагинация и период** у нового шаблона оставьте `{"type":"none"}` в JSON правил и `null` в **Разбиение периода (JSON)**. Один ID даёт один ответ, а даты из ответа являются полями кампании.

Раскройте **Параметры запроса**. Замените содержимое большого поля **Определения параметров** на этот массив.

```json
[
  {
    "name": "id",
    "label": "ID медиакампании",
    "where": "query",
    "type": "integer",
    "required": true,
    "min": 1
  }
]
```

`name` задаёт имя `id`, которое ожидает WB. `where: "query"` помещает значение после `?id=`. `integer` и `min: 1` проверяют, что в форму введено целое положительное число. Возьмите его из поля `advertId` нужной записи списка.

## 3. Настройте ответ и листы Excel

Раскройте **Ответ и колонки**. В **Путь к массиву строк** введите `$`. Этот путь выбирает корень ответа с `advertId`, `name`, `extended` и `items`.

В большое поле **Колонки** под кнопкой **Добавить колонку** вставьте массив для основного листа. Поле `path` берёт значение из объекта кампании, `name` становится заголовком колонки.

```json
[
  { "path": "advertId", "name": "ID кампании" },
  { "path": "name", "name": "Название кампании" },
  { "path": "brand", "name": "Бренд" },
  { "path": "type", "name": "Тип" },
  { "path": "status", "name": "Статус" },
  { "path": "createTime", "name": "Создана" },
  { "path": "extended.from", "name": "Начало" },
  { "path": "extended.to", "name": "Окончание" },
  { "path": "extended.budget", "name": "Бюджет" },
  { "path": "extended.expenses", "name": "Расходы" },
  { "path": "extended.reason", "name": "Причина остановки" }
]
```

В поле **Проверка успеха, массивы и дедупликация (JSON)** ниже вставьте объект. Оставьте `tables`, если нужен отдельный лист по баннерам.

```json
{
  "singleObject": true,
  "allowNoContent": true,
  "tables": [
    {
      "name": "Баннеры",
      "path": "items",
      "columns": [
        { "path": "$parent.advertId", "name": "ID кампании" },
        { "path": "id", "name": "ID баннера" },
        { "path": "name", "name": "Название баннера" },
        { "path": "status", "name": "Статус баннера" },
        { "path": "place", "name": "Место размещения" },
        { "path": "category_name", "name": "Категория" },
        { "path": "cpm", "name": "CPM" },
        { "path": "budget", "name": "Бюджет баннера" },
        { "path": "daily_limit", "name": "Дневной лимит" },
        { "path": "date_from", "name": "Начало показа" },
        { "path": "date_to", "name": "Конец показа" },
        { "path": "url", "name": "Ссылка" }
      ]
    }
  ]
}
```

- `singleObject` сохраняет объект ответа как строку кампании. Поля `extended.*` становятся обычными колонками этой строки.
- `allowNoContent` принимает статус `204`, которым WB сообщает, что медиакампания не найдена. Такой ответ даёт ноль строк и выгрузка переходит к следующему ID.
- `tables` открывает массив `items` для каждой кампании. `$parent.advertId` повторяет ID кампании в каждой строке её баннера, а `id` берёт ID самого баннера. По колонке **ID кампании** листы можно связать в Excel.

## 4. Настройте лимит и проверьте один запрос

В **Лимиты и восстановление → Дополнительные ограничения (JSON)** для персонального, сервисного и базового токена с секретом вставьте правило из документации метода.

```json
[{ "id": "wb-media-campaign-detail", "type": "bucket", "refillMs": 100, "burst": 10 }]
```

Для обычного базового токена замените его на следующее правило.

```json
[{ "id": "wb-media-campaign-detail", "type": "bucket", "refillMs": 720000, "burst": 1 }]
```

Интервал в `refillMs` задан в миллисекундах. Для обычного базового токена это 12 минут между запросами деталей. Выгрузка 100 кампаний займёт примерно 20 часов без учёта повторов. Для этого читающего `GET` можно включить **Безопасно повторять при временной ошибке** и выбрать **Продолжить с контрольной точки**.

Нажмите **Сохранить и протестировать**, выберите среду **Рабочая**, впишите `advertId` известной кампании в поле **ID медиакампании** и нажмите **Выполнить запрос**. В **Журнал → Подробнее** при статусе `200` должна быть одна строка кампании. Полный ответ с `extended` и `items` можно посмотреть через **Просмотр строк** или **Шаблоны запросов → Ещё → Образец ответа**. При статусе `204` попробуйте другой ID из списка.

## 5. Подключите все ID из списка

1. У **Списка медиакампаний** откройте **Ещё → Версии** и раскройте последнюю опубликованную версию. Скопируйте верхнее поле `id` у объекта с `name` вашего списка. Это ID шаблона MP API. Числовой `advertId` приходит от WB, а верхнее `id` в `результат.json` обозначает конкретный запуск выгрузки.
2. Откройте **Настроить → Параметры запроса** у нового шаблона деталей. Замените весь массив параметров для ручного теста на следующий и подставьте скопированный `id` вместо `ID-ИЗ-ШАБЛОНА-СПИСКА`.

   ```json
   [
     {
       "name": "id",
       "label": "ID медиакампаний",
       "where": "query",
       "type": "array",
       "items": { "type": "integer", "min": 1 },
       "required": true,
       "minItems": 1,
       "batchSize": 1,
       "encoding": "csv",
       "reference": {
         "templateId": "ID-ИЗ-ШАБЛОНА-СПИСКА",
         "mode": "all",
         "refresh": "run",
         "path": "advertId"
       }
     }
   ]
   ```

3. `path: "advertId"` берёт поле из каждой строки ответа списка. `mode: "all"` собирает уникальные ID, а `refresh: "run"` выполняет опубликованный список перед запуском деталей. Если вы задавали фильтры списка вручную в выгрузке, заполните нужные `default` в шаблоне списка и опубликуйте его заново. Именно эти настройки получает зависимый запуск.
4. Массив нужен программе, чтобы собрать все ID. `batchSize: 1` берёт по одному элементу, а `encoding: "csv"` передаёт единственное число в строке запроса. Например, из `[23569,24680]` получатся два запроса с `?id=23569` и `?id=24680`.
5. Нажмите **Сохранить и опубликовать версию**. Затем **Тест** выполнит весь запрос списка и первый запрос деталей. В **Журнал → Подробнее** видны оба источника. Пункт **Параметры запуска** карточки деталей показывает собранные ID, для длинного списка — общее число и первые 100.

## 6. Запустите выгрузку деталей

Для запуска под ролью **Пользователь** включите **Доступен пользователям в выгрузках** у обоих шаблонов и опубликуйте их.

В **Выгрузки → Создать выгрузку** выберите подключение, папку и шаблон **Информация о медиакампаниях WB**. Оставьте среду **Рабочая** и **Без обработки**, выберите **Excel (.xlsx)**. В этой выгрузке достаточно одного источника — шаблона деталей. Приложение само выполнит список перед ним.

Сохраните и запустите выгрузку. В **Журнал → Подробнее → Открыть папку файлов** будет Excel с листом кампаний и, если указали `tables`, листом **Баннеры**. В каждом новом запуске список ID собирается заново из ответа `/adv/v1/adverts`.
