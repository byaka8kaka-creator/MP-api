# Обработка всей выгрузки

Во вкладке **Обработки** можно настроить обработку **Одного источника** или **Всей выгрузки**. Вторая область позволяет соединить данные разных запросов, рассчитать итоги и задать листы Excel или таблицы CSV. Настройку можно проверить на ранее сохранённом запуске.

## 1. Укажите источники

1. Откройте **Обработки → Новая обработка → Область обработки → Вся выгрузка**.
2. Для каждого источника выберите **Опубликованный шаблон** и введите **Имя набора**, например `sales` или `products`. Имена наборов и выходных полей можно составить из латинских букв, цифр, `_` и `-`. В заголовках листов и колонок можно использовать русский текст.
3. Если один шаблон добавлен в выгрузку несколько раз, укажите **Номер источника с этим шаблоном**. Нумерация начинается с 1 и учитывает только карточки с выбранным шаблоном в порядке их добавления. Данные зависимых запросов можно обработать, добавив эти шаблоны в выгрузку как источники.
4. При необходимости включите **Читать все строки, включая дубли из разных ответов**. Это нужно, например, когда один ID кампании встречается в нескольких частях периода, а шаблон удаляет дубли по ID.

Приложение берёт строки из пути, указанного в шаблоне запроса в разделе **Ответ и колонки**. Если там настроен `data.products`, поля внутри каждой записи доступны как `product.nmId`, `product.brandName` и так далее. Чтобы добавить в запись даты или другие параметры формы, откройте **Поля из параметров запроса**. Например, для пути `from` и имени `beginDate` в записи появится поле `request.beginDate` с фактическим началом периода каждой части запроса. Значения дат задаются в карточках источников выгрузки.

## 2. Настройте шаги

Для каждого шага укажите **Набор на входе** и **Имя результата**. Входом может быть источник или результат шага выше по списку. Исходный набор остаётся доступен для других шагов и листов.

У полей пути в шагах и колонках нажмите **Выбрать поле** для поиска по имени или пути. Для источника список строится из сохранённого образца теста, а для результата предыдущего шага учитывает разворот массивов, перенос, соединение и группировку. Например, у исходного отправления Ozon можно выбрать `products`, а после разворота этого массива в `item` — `item.offer_id`. Поле пути также принимает ручной ввод, в том числе при отсутствии образца.

| Шаг | Что задаётся |
| --- | --- |
| **Соединение наборов** | Набор-справочник и пары полей для сравнения. Ключи можно сравнивать по значению и типу, как текст или как целое число. Сравнение как целого числа подходит, если в одном ответе ID числовой, а в другом строковый. |
| **Разворот массива** | Путь к массиву и имя поля для элемента. Например, `nms` и `item` дают отдельную строку на каждый товар с артикулом по пути `item.nmId`. |
| **Перенос полей** | Какие поля скопировать и как их назвать. Флажок **Сохранить остальные поля строки** оставляет остальные данные на выходе шага. |
| **Список значений в одной ячейке** | Массив, путь к значению, разделитель и подпись для пропуска. Подходит для списка артикулов или брендов. |
| **Удаление дублей** | Поля, по которым определяется повтор. Первый экземпляр ключа попадает в результат. |
| **Распределение показателей по детализации** | Поля с группой и ключом товара, путь к детализации, общие показатели и их значения в детализации. Если групп несколько, можно распределить значения при совпадении итогов или отнести общий итог в одну строку. |
| **Группировка и итоги** | Поля группировки и итоговые показатели. Доступны сумма, количество строк, количество разных значений, минимум и максимум. При группировке расходов можно потребовать одинаковую валюту. |

В соединении можно вложить все совпадения списком, сделать по строке на каждое совпадение, взять первое или взять одну строку, если все найденные записи одинаковые. При отсутствии совпадения можно оставить исходную строку, пропустить её или считать это ошибкой. Например, при соединении по артикулу с полем для совпадения `product` бренд из справочника доступен как `product.brandName`.

## 3. Укажите листы и проверьте результат

1. Откройте **Листы результата**. Добавьте нужные листы, выберите набор для каждого и задайте пути и заголовки колонок. Кнопка **Добавить листы этого шаблона** в карточке источника переносит исходные листы шаблона в обработку. Их состав и порядок можно отредактировать.
2. При необходимости включите **Развернуть массив на листе**. При использовании полей элемента путь `views` берёт значение из элемента, а `$parent.advertId` — из исходной строки.
3. В блоке **Проверка на сохранённом запуске** выберите запуск с нужными источниками и нажмите **Предпросмотр**. Проверьте количество строк, пропуски, конфликты и образцы листов. После изменения источников нажмите **Обновить список запусков**.
4. Сохраните обработку. В **Выгрузках** добавьте требуемые источники и выберите обработку в поле **Обработка всей выгрузки**. Эта настройка используется при ручном запуске и по расписанию.

Режим **JSON** показывает те же настройки в массивах `sources`, `steps` и `sheets`. Можно изменить их и переключиться обратно в **Конструктор шагов**. Например, `input` и `output` — имена входного и выходного наборов шага, а `sheets[].columns` — список пар `path` и `name` с путём к значению и названием колонки.

В **Журнал → Подробнее** кнопки **XLSX** и **CSV** используют настройки, сохранённые при запуске. Чтобы построить отдельный файл из тех же ответов по текущей обработке, нажмите **Применить обработку выгрузки**. Для этого используются сохранённые ответы API.
